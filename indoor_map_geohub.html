🎨Style Studio 使用步骤

登录 GeoHUB

访问 geohub.amap.com，使用高德账号登录（需与 Key 同一账号）

创建自定义样式

点击「样式」→「创建样式」→ 选择「基础底图样式」→ 在可视化编辑器中调整：背景色、建筑颜色、道路色、字体等

发布并获取 Style ID

编辑完成后点击「发布」→ 复制生成的样式 ID（格式：amap://styles/xxxxxxxx）

填入下方输入框

将完整的样式 ID（如 amap://styles/f8a234ab5c6d...）粘贴到「GeoHUB 样式 ID」输入框并应用

🗄️Data Hub 使用步骤

进入数据中心

GeoHUB 控制台 → 「数据中心」→「上传数据」

上传室内地图数据

支持 GeoJSON / CSV 格式。上传 POI 数据（名称、坐标、分类）或楼层平面图（SVG/DXF）

发布为 API

数据发布后，在「API」页面获取数据查询接口地址，填入下方 GeoHUB Data URL

代码中调用

使用 fetch() 调用 GeoHUB Data API，将返回数据注入 Three.js 楼层模型

⚙️API 接入方式

样式接入

map.setMapStyle('你的StyleID')

数据接入

fetch('GeoHUB Data API URL') → 解析 POI → 注入 Three.js

坐标统一

GeoHUB Data 中的坐标直接用于 lngLatTo3D() → Three.js 世界坐标
