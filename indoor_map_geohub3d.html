地图加载需要有效的 Web 端 JS API Key。

1. 打开 https://console.amap.com/dev/key/app
2. 创建 Web 端 JS API Key（不是 Web 服务 API）
3. 添加域名白名单: localhost, 127.0.0.1
4. 复制 Key，替换 HTML 中 key=YOUR_KEY_HERE
5. 刷新页面

如果已有 Key，直接修改文件第 7 行替换即可。
