# 室内 3D 地图项目

基于 **高德地图 JS API 2.0** + **Three.js r128** 的室内空间 3D 可视化与自定义建模系统：室外地图上任意建筑均可一键进入 3D 漫游，支持楼层管理、自定义建模、跨层导航、房间级内部建模、**多用户同房间实时轨迹演示**，并可对接定位系统后端接入真实位置数据。**纯前端单文件**实现，CDN 依赖，零构建。

## 功能特性

**室外地图与 3D 漫游**
- 高德标准地图，搜索/点击任意建筑一键进入 3D 室内漫游（不限商场）
- 3D 场景：玻璃外墙、逐层楼板、店铺网格（品类配色）、CSS2D 标签、悬停/点击/楼层切换、视角旋转缩放
- 退出 3D 自动 `map.resize()` 修复地图尺寸

**店铺导航与定位**
- 室内跨层导航：绿色路径 + 移动球，优先经真实电梯/扶梯/楼梯，无设施回退中庭
- 标记「我的位置」：图钉 + 光圈 + 坐标面板，跨重建/跨楼层恢复

**自定义 3D 建模**
- 整栋/逐层独立编辑：楼层尺寸、店铺网格、中庭、轮廓
- 自由绘制建筑轮廓（Shape + ExtrudeGeometry，射线法裁剪店铺）
- 内墙隔断（逐段添加/删除/撤销/清空）
- 店铺编辑：新增/删除/复位/拖动移动/改色（品类）、**6 种形状**（矩形/圆形/L/T/U/十字/弧形）、尺寸滑块、旋转朝向
- 设施放置：电梯/扶梯/楼梯/中庭喷泉
- 一键清空全部建模（从零设计）与一键重新生成网格
- JSON 室内数据导入导出 + 模板下载 + 随机样例生成

**房间级内部建模（点击店铺进入房间）**
- 独立房间 3D 视图：房间内部家具/设备/装饰建模，支持房间数据上传生成
- 房间尺寸按标签坐标自动扩大（后端数据超界时自动重建容纳）

**多用户同房间实时轨迹（核心演示功能）**
- 房间页顶部「多用户轨迹」主功能条：一键演示 **3 人并行游走**，按用户分色小圆球 + 实时轨迹线，在线人数/轨迹点数实时统计
- `IndoorRoomAPI.push({id, x, z})`：任意多用户按 id 分色追踪，同房间各自独立轨迹
- 对接定位系统后端：登录后每 2s 拉取标签位置，`device_id` 作为用户 id 分色显示（后端 y → 前端 z 坐标映射）

**持久化与健壮性**
- `indoor3d_edConfig`：自定义建模（尺寸/店铺/墙/设施/轮廓）自动保存到 localStorage，刷新不丢
- 高德 CDN 加载失败自动降级提示；Three.js 按需懒加载（首屏不下载）；WebGL 资源 dispose 防泄漏
- 无真实高德 Key 时演示模式仍可跑（mock 楼层数据兜底）

## 快速体验

1. 打开页面 → 搜索/点击一个建筑 → 进入 3D 室内漫游
2. 点「⚙ 自定义」调整尺寸/加墙/编辑店铺/放设施
3. 点击任意店铺 → 「进入房间 3D 建模」→ 房间页顶部「**多用户轨迹**」主功能条，连接定位后端后即可看到多用户同房间运动轨迹
4. 定位后端连接成功后，标签按 `device_id` 分色显示为小球 + 实时轨迹

## 使用前：配置你自己的高德 Key

> ⚠️ **本仓库不含任何真实高德 Key**（已统一替换为占位符），请使用你自己的 Key，避免配额被盗用。

1. 前往 [高德开放平台](https://lbs.amap.com/) 申请 **「Web 端 (JS API)」** 类型的 Key，并配置 **安全密钥 (securityJsCode)**。
2. 在 HTML 文件中，将以下两处占位符替换为你的密钥：
   - `YOUR_AMAP_KEY_HERE` → 你的高德 Key
   - `YOUR_AMAP_SECURITY_CODE` → 你的安全密钥
3. （可选）文档 `PROJECT.md` 等中的 `YOUR_AMAP_KEY_HERE` 同理替换。

> 提示：不同 HTML 顶部引入高德脚本的方式略有差异，请确认每个文件里的 `key=` 与安全密钥都已替换。

## 定位系统后端对接

房间页支持对接标签定位服务后端（FastAPI 风格，`/api/v1/auth/login` 登录 + `/api/v1/tags/positions` 拉取标签位置）：

- **打开即用**：页面加载后自动连接（默认账号 `admin` / `admin123`），无需手动填写；换过账号会存入 localStorage 记住
- 后端返回 `{device_id, position:{x, y}}` → 前端按 `device_id` 分色显示为房间内多用户轨迹（`y` 映射为前端 `z`）
- token 失效自动重新登录；退出房间页自动断开
- 还支持客户端角色接口：标签列表 `/tags`、单标签历史轨迹 `/tags/{id}/positions`、单标签事件 `/tags/{id}/events`、全局事件 `/events`

### 获取本仓库后，如何对接后端（重要）

后端接口一般有 CORS 限制（浏览器直连会被拦），推荐用仓库自带的**同源代理**：

```bash
# 方式一：环境变量指定后端地址（推荐）
BACKEND_TARGET=http://你的后端IP:8000 node proxy_server.js

# 方式二：命令行参数
node proxy_server.js http://你的后端IP:8000

# 方式三：不传参数，改 proxy_server.js 顶部 DEFAULT_TARGET 默认值
node proxy_server.js
```

然后浏览器打开 **http://localhost:8080** → 房间页左下「连接定位后端」**地址留空**（自动走当前源，无跨域问题）→ 输入用户名/密码 → 连接即可。

**不想用代理时**（后端已开 CORS）也可以直连，二选一：

- 打开页面时带参数：`http://你的站点/?backend=http://后端IP:8000`
- 或房间页左下「后端地址」输入框直接填后端地址（留空 = 当前站点）

## 本地运行

直接用浏览器打开对应 HTML 即可（需联网加载高德地图与 Three.js 的 CDN）。

如遇到浏览器对本地文件的限制，建议用本地静态服务器：

```bash
# 在项目目录下
python -m http.server 8000
# 然后访问 http://localhost:8000/indoor_map_final_backup_20260729_0921.html
```

## 目录说明

- `indoor_map_*.html` —— 各阶段版本
