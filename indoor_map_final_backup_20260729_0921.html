3D 建模自定义 · 教程
第 1 / 9 步
上传室内数据生成建模

支持 .json 文件或粘贴 JSON 文本。数据将覆盖当前建模，按楼层 / 店铺 / 墙 / 设施生成 3D 模型。也可点「随机样例」生成演示数据（基于随机数接口）。格式说明：building 含尺寸，floors[] 每层含 shops/walls/facilities。载入成功后弹窗保持打开，可直接换一份数据继续点「载入并生成建模」反复测试；点「取消 / ✕」关闭弹窗查看 3D 效果。

上传房间内部数据（房间级建模）

支持 .json 文件或粘贴 JSON 文本。数据对应当前选中的房间，也可用 room 字段指定房间名。格式：{room, items:[{name,cat,x,z,w,d,h,shape,rot}], walls:[{x1,z1,x2,z2}]}——x/z 为以房间中心为原点的相对坐标（米），cat 可选 furniture/device/decor/other。载入成功后弹窗保持打开，可连续换数据测试；点「取消 / ✕」关闭查看 3D。
